# 検査値の参照値の出典

`manifest.json` は、抽出結果の検証が単位なしの電解質の数値を検査値と読む範囲（`mcs/extract/clinical/clinical_values.py` の `_UNIT_LESS_BANDS`）と、その出典を記録します。範囲はコードに定数として持ち、実行時にこのファイルは読みません。両者が一致することはテスト（`tests/extract/clinical/test_lab_names_gen12.py`）が確かめます。

- 範囲は日本臨床検査医学会（JSLM）「臨床検査『パニック値』運用に関する提言書」の例示値（ナトリウム 115〜165 mmol/L、カリウム 1.5〜7.0 mmol/L、カルシウム 6.0〜12.0 mg/dL、両端を含む）です。配布元が取得を拒否したため原本を確認できておらず、`verified_from_primary`・`edition_verified` は `false`、取得日ではなく `retrieval_attempted_on`（取得を試みた日）を記録しています。版の表記も未確認です。所有者が原本を確認するまで、値は検索結果に基づく暫定です。
- 日本臨床検査標準協議会（JCCLS）の共用基準範囲（2022/10/01 版）は原本を取得し、SHA-256 とバイト数を記録しました。コードはこの値を使いません。
- マグネシウムはどちらの資料にも値がないため範囲を置きません。単位の書かれていないマグネシウムの数値は常に未確認候補として値を残します。
- 範囲外の値も捨てません。未確認候補として値を残します。原本に単位が書かれていれば範囲は適用しません。
