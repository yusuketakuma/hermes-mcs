# 処理サービスのアイコン

各投稿の処理に使ったサービスを識別するための素材です。提携や各社による推奨を示す表示ではありません。取得元と原本のSHA-256は `manifest.json` に保存しています。

- Anthropicは公式サイトのタッチアイコンです。
- JevはTypeSafe AI公式サイトのアイコンで識別します。Jev専用のロゴとは区別します。
- OpenAIは公式GitHub組織の公開アバターです。白い背景を含む原本をそのまま使います。取得済みのLobeHub Icons 2.5.0の公開PNGも `openai-fallback.png` に保持し、そのMITライセンスの本文を `LOBEHUB-LICENSE.txt` に同梱しています。OpenAIの商標利用条件は https://openai.com/brand/ を参照してください。
- ローカル用PCはBootstrap Icons 1.13.2の `pc-display.svg` です。MITライセンスの本文を `BOOTSTRAP-LICENSE.txt` に同梱しています。PNGは同じ図形をmacOSのsipsで描画したものです。

会社のロゴを加工して処理状態を表さず、ロゴとは別の印で状態を示します。PNG・SVGには投稿内容や患者情報を含めません。実行時に使う画像URLは固定の公開素材だけとし、患者IDや投稿IDを付加しません。
