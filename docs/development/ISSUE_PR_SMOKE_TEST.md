# Issue→PR 動作確認用テスト文書

この文書は、Issue から通常 PR が作られる流れを確かめるための**完全合成**の動作確認用文書です。
実機・実データ・患者情報・実ログ・秘密値は含みません。
本番の稼働や安全性を証明するものではありません。

運用の正本は `docs/development/AUTOMATION.md` です。

## 目的

Issue の詳細化、担当の付与、通常 PR の作成、CI と `merge-gate` の確認、所有者の判断までの流れが、
文書1ファイルの変更で一通り進むかを確かめます。

## 流れ

1. Issue を詳細化する。
2. 所有者が担当ラベルを付ける。
3. 担当が通常 PR（下書きにしない）を作る。
4. CI と `merge-gate` の結果を確認する。
5. 所有者がマージの可否を判断する。マージ・タグ・リリース・配備はこの文書の対象外。

## 確認項目（すべて未確認）

サンプル識別子: `SYNTHETIC-SMOKE-001`

- [ ] Issue が詳細化されている
- [ ] 担当ラベルが1件だけ付いている
- [ ] 通常 PR が1本作られている
- [ ] CI が完了し、結果を確認した
- [ ] `merge-gate` が完了し、結果を確認した
- [ ] 所有者がマージの可否を判断した
