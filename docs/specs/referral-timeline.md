# 診療情報提供書の項目と経過タイムライン

## 対象と項目

OCR原文に「診療情報提供書」または「紹介状」の独立した見出しがある資料を対象にします。
厚生労働省の別紙様式11とJP-CLINSの項目を参考に、次の内容を原文の見出し単位で整理します。
見出しのない文章も残しますが、対応しない見出しは分類できない場合があります。

| 区分 | 読み取る項目 | 扱い |
| --- | --- | --- |
| 基本情報 | 紹介先・紹介元、医療機関、診療科、医師、患者氏名、生年月日、性別、年齢、職業、住所、電話、文書作成日 | 文書の基本情報。診療上の出来事にはしない |
| 紹介内容 | 傷病名、紹介目的、備考 | 記載内容と出典を保持 |
| 病歴・経過 | 既往歴、家族歴、現病歴、症状経過・検査結果、治療経過 | 明示された日付と引用を対応付ける |
| 処方・背景 | 現在の処方、アレルギー、生活背景、療養方針など、既存の医療文書分類に対応する欄 | 記載内容と出典を保持。現在の診療方針や処方と断定しない |

「既往歴及び家族歴」の複合欄は一つの欄として残します。家族の病歴を患者本人の病歴へ移しません。
否定、予定、訂正は引用に残します。同じ物理行にある文は句点で分割せず、訂正文を元の記載から切り離しません。
別行にまたがる訂正の対応付けや、自由記載の臨床的な関係の確定は行いません。

## 日付と時系列

`referral_document.project`は保存済みのページ本文から項目と日付を取り出す、標準ライブラリだけの処理です。
追加のLLM照会は行いません。日付は原文、正規化した値、精度、妥当性、用途を持ちます。

| 原文の例（合成） | 保存する値・精度 | 表示 |
| --- | --- | --- |
| 2026年11月5日 | `2026-11-05` / `day` | 日付順 |
| 2026年11月 | `2026-11` / `month` | 月までの記載として日付順 |
| 2026年 | `2026` / `year` | 年までの記載として日付順 |
| 11月5日 | `--11-05` / `month_day` | 時点不明。年は補わない |
| 2026年11月5日〜7日 | 複数の日付候補。末尾の省略された年月は補わない | 時点不明 |
| 翌日、最近、日付なし | 正規化した日付なし | 時点不明 |

西暦の年月日・年月・年、年月日のハイフンまたはスラッシュ表記と、明治以降の元号に対応します。
不正な日付や元号の境界外は有効な日付にしません。明治6年より前の月日は旧暦から変換しません。
複数の異なる日付がある行は、一つの出来事の日付へ決めません。
年・月だけの値はその精度のまま並べ、同じ期間内の前後関係までは主張しません。

日付の用途は`event`（出来事の記載）、`document`（文書の情報）、`birth`（生年月日）に分けます。
日付だけの行は用途未確認の基本情報とし、直前の臨床欄の日付にしません。
明示された生年月日・文書作成日の欄が次行へ続く場合は、その用途を維持します。
見出しだけの行も出来事にはしません。作成日、生年月日、投稿日時、添付の取得日時から診療日時を補いません。

## 保存済み資料との照合

`referral_reader.read`は呼出元のDB接続に読取りスナップショットを借り、対象患者の現行資料だけを読みます。
アーカイブ・閲覧禁止の患者、削除された投稿、変更・撤回された添付や古い解析は採用しません。
文字のある全ページで、既存のローカル・必要なクラウド解析の完了と原資料との一致を確認します。
未完了の資料は保留件数に残します。

各項目・記載は、親投稿、添付ID、ページ、原文と解析の保存記録、内容ハッシュ、引用範囲に結び付けます。
引用がページ本文と一致しなければ採用しません。原文や既存の解析結果は変更しません。
新しいDB形式、外部送信、追加課金、臨床事実の自動確定は追加しません。

読取りは新しい添付から最大50件、本文合計8MiB、処理の区切りで1秒を確認します。
1回の内側の読取りを強制中断する制限ではありません。
項目・記載・日付候補の合計は1資料4096件までです。上限や未解析があれば点検未完了を表示し、
未処理部分のページと位置を返します。範囲外の過去資料まで確認済みとは扱いません。

## 表示と既存機能への影響

患者コンテキストの「経過タイムライン」で、既存の投稿順の記録に続けて、
「紹介状の記載（日付順）」「紹介状の記載（時点不明）」「紹介状の基本情報」を表示します。
投稿の時系列と資料に記載された時系列は分けます。既存の患者コンテキストの内容や並びは変えません。

これは原文の記載を読むための時系列です。検査・バイタルの数値系列、薬剤イベント、PCAの構造化候補を
この処理から新たに登録するものではありません。これらは既存の各解析・採用条件に従います。
