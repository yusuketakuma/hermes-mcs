# 処理サービスの表示

カード見出しの日時・投稿数と同じ欄に、Anthropic・OpenAI・Jev・ローカルLLMのアイコンを並べます。現在の表示結果と原文に対応する記録から、そのサービスの関与を確認します。キーが登録されているだけでは、処理済みにはなりません。

カード最上部は従来の固定アイコン💬を使います。投稿ごとの実行記録は詳細に残し、カード面では見出し欄だけに表示します。

1投稿のカードでは次の状態を表示します。

| 印 | 状態 |
|---|---|
| ✓ | 現在の結果の生成・検証への関与を確認済み |
| ✓↷ | Jevで一部を実行し、残りを省略 |
| ↷ | Jevの検証を省略した記録あり |
| … | 処理待ち |
| − | 未使用 |
| ! | 失敗 |
| ? | 実行状況を確認できない |

複数投稿を表示するカードでは、表示中の投稿に実行の証拠が1件以上あれば「使用あり」、確認できなければ「不明」と表示します。「使用あり」は全投稿の処理完了を表しません。ページを切り替えると、そのページの投稿に対応する表示へ変わります。

ローカルはこのMac上のLLMを指します。記録の保存やルールによる整理の状態は、このアイコンの判定に含みません。

実行結果が表示に採用されなかった呼出しや、過去の記録だけでは実行の有無を確認できない場合は、不明にします。クラウドへの送信後に失敗してローカル処理へ切り替わった場合も、クラウドを未使用とは断定しません。

アイコンは結果の生成・検証への関与を示し、Jevの検証結果の合否とは区別します。ロゴの形や色は変えず、別の印で状態を示します。代替テキストにはサービス名と状態を含めます。

SlackではAnthropic・OpenAI・Jevの画像とローカルの💻を使います。画像を並べられない通知先では、サービス名と状態を文字で表示します。

素材の出典とライセンスは [アイコンの説明](../../resources/provider-icons/README.md)を参照してください。同梱素材は説明図にも使い、Slackでは固定の公開URLから画像を表示します。URLに投稿内容や患者情報を付加しません。
