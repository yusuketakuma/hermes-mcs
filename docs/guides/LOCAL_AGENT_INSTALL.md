# デスクトップ版のClaude・Codexから導入する

Claude（デスクトップ版）やCodexなどのAIエージェントに、このMacへのMCS導入を任せるときの手順です。
エージェントはリポジトリを一時的な作業フォルダへ取得することが多いため、そのまま`install.sh`を実行すると、
常駐サービスやプラグインが一時フォルダを参照してしまいます。
`scripts/install_local.py`は、恒久的な置き場所を決めてから、その場所の`install.sh`を実行します。

```bash
python3 scripts/install_local.py              # 置き場所を自動で決めて導入
python3 scripts/install_local.py --dry-run    # 計画だけを表示（何も書き込まない）
python3 scripts/install_local.py --dest "/path/to/folder" --mode standalone
```

`--dest`と`--dry-run`以外の引数は、そのまま`install.sh`へ渡します（`--mode`・`--no-llm`など）。
macOS標準の`python3`（3.9以上）で動くため、Python 3.14の導入前でも使えます。Python 3.14は`install.sh`が導入します。

## 置き場所の決め方

| 状況 | 動作 |
|---|---|
| `--dest`を指定しない・既存の導入記録がある | 前回`install.sh`が記録した置き場所（`~/.mcs-recovery/repo_path`）をそのまま使う |
| `--dest`を指定しない・初回 | `~/.mcs`へ新しく取得する |
| `--dest`を指定しない・`~/.mcs`に設定やデータだけがある | `~/.mcs`には触れず、`~/.local/share/hermes-mcs`へ取得する |
| 置き場所が存在しない・空のフォルダ | 取得元の commit 済みの内容をそこへ取得する。`origin`は取得元と同じリモートにする |
| 同じプロジェクトの同じ版の checkout がある | 書き換えずにそのまま使い、その場所の`install.sh`を再実行する |
| 同じプロジェクトの別の版の checkout がある | 導入も版の変更もせずに止める。[更新手順](UPGRADE_AGENT.md)で移行先の版の更新ツールを使う |
| 別のプロジェクト・空でないフォルダ・設定やデータだけがあるフォルダ・ファイル | 導入せずに止める。既存のデータは移動しない |

MCSの設定と収集データは、checkout の置き場所に関係なく`~/.mcs`に保存されます。
Hermes agentや独立実行のPython環境・ローカルLLMのモデルの置き場所は、従来どおり`install.sh`が決めます（[導入ガイド](INSTALLATION.md)）。
取得元に commit されていない変更がある場合は表示し、導入先には commit 済みの内容だけを入れます。
取得は隣の一時フォルダで行ってから置き場所へ移すため、途中で止まっても不完全な checkout は残りません。再実行すれば続きから導入できます。

## ローカル実行でない環境では導入しない

次のどれかに当たる場合は、ユーザーのMacのローカル実行ではない可能性があるため、何も書き込まずに終了します（終了コード3）。

- macOSではない、またはユーザーのログインセッション（launchdのguiドメイン）に届かない
- ホームフォルダに書き込めない、`git`がない

この場合は、表示されたコマンド（パスは引用済み）を利用者自身がMacのターミナルで実行してください。
エージェントのチャット画面やクラウド上の実行は、ローカルのファイル・プロセス操作の権限がなければ導入を完了できません。
`install.sh`の「ソフトの準備が完了しました」と各段階の結果を確認します。初期設定を後回しにした場合は案内に従って再開し、その後の`mcs doctor`と接続確認まで進めます。終了コード0だけで利用開始済みとは判断しません。
サンドボックスを示す環境変数（`CODEX_SANDBOX`など）は参考として表示するだけで、上の条件に当たらなければ導入を続けます。

| 終了コード | 意味 |
|---|---|
| 0 | ソフトの準備が完了した（初期設定を後回しにした場合は未完了）。`--dry-run`は計画表示のみ、事前チェックは確認のみ |
| 2 | 置き場所や取得元が安全でない、または未配置のため事前チェックを実行できない |
| 3 | ローカル実行でない可能性があるため止めた |
| 4 | 取得に失敗した（途中の作業フォルダは削除済み） |
| 130 | 導入前に中止した、または開始した初期設定を中断した。ソフトの準備結果と再開案内を確認する |
| その他 | `install.sh`の終了コード |

導入後の初期設定は[導入ガイド](INSTALLATION.md)と[AIエージェント向け導入手順](SETUP_AGENT.md)に従います。
