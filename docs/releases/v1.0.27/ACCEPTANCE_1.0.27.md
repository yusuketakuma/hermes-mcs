## 新規導入・更新・復旧

新規設定は辞書未設定時のみ既定「はい」の提案を追加し、確認日・確認者・採用承認を運用者が入力します。既存設定と`init --yes`の自動承認なしは保持します。Hermesとstandaloneは同一plistからレーン引数を使います。
