変更記録37件（新機能12・改善8・不具合修正17）を含みます。v1.3.0は、ローカルの患者画面に在宅ケアの患者台帳・職員・ケアチーム・訪問歴・処方歴・訪問ルートを追加し、医薬品の検索・照会の共通入口や、添付文書改訂から言及患者を探す機能を新設しました。意味解析と抽出監査に使う Jev を jev-1.14.0 へ更新し、新モデルへの切替は確認に合格したときだけコマンドで行います。書込みロックの待ち、意味解析・QCの滞留、クラウド費用集計、新規導入の途中停止に加え、状態不明の常駐処理起動、上限超過した薬名辞書の再走査、条件不変のクラウド再処理も抑えます。

| 以前 | v1.3.0 | 利用者のメリット |
