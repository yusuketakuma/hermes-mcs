v1.3.0は、ローカルの患者画面に在宅ケアの患者台帳・職員・ケアチーム・訪問歴・処方歴・訪問ルートを追加し、医薬品の検索・照会の共通入口や、添付文書改訂から言及患者を探す機能を新設しました。意味解析と抽出監査に使う Jev を jev-1.14.0 へ更新し、新モデルへの切替は確認に合格したときだけコマンドで行います。書込みロックの待ち、意味解析・QCの滞留、クラウド費用集計、新規導入の途中停止などの不具合も修正しています。

| 以前 | v1.3.0 | 利用者のメリット |
| --- | --- | --- |
| 在宅ケアの患者台帳・職員・訪問・処方歴をローカルで一元管理する画面がない | 患者画面に台帳と訪問・処方歴を追加 | 患者ごとの在宅ケア情報をまとめて確認・記録できます |
| 医薬品辞書からの共通検索と、患者の言及を横断して探す入口がない | 検索・照会の共通入口と患者横断検索を追加 | マスター差分や添付文書改訂に関連する患者を探せます |
